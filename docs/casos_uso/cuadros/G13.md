## G13 Gestionar funcionarios y usuarios

Épica EP-08 (Administración, seguridad y trazabilidad). 4 casos de detalle para Administrador.

### CU-104 Registrar funcionario

| Campo | Descripción |
| --- | --- |
| Identificador | CU-104 |
| Nombre | Registrar funcionario |
| Actor principal | Administrador |
| Propósito | Incorporar un funcionario nuevo. |
| Precondiciones | Sesión iniciada con permiso para agregar. |
| Postcondiciones | Funcionario guardado. |
| Flujo principal | Elegir «Agregar», completar el formulario, validar y guardar. |
| Casos incluidos | CU-108 Validar datos de funcionario; CU-109 Asignar perfil de acceso; CU-45 Registrar en auditoría |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 |
| Pantalla | `/administracion/funcionarios/nuevo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-107 Eliminar funcionario

| Campo | Descripción |
| --- | --- |
| Identificador | CU-107 |
| Nombre | Eliminar funcionario |
| Actor principal | Administrador |
| Propósito | Quitar un funcionario que ya no corresponde. |
| Precondiciones | El funcionario existe. |
| Postcondiciones | Registro eliminado, o desactivado si tiene datos relacionados. |
| Flujo principal | Buscar el registro, revisar la confirmación y confirmar. |
| Casos incluidos | CU-29 Buscar y filtrar; CU-45 Registrar en auditoría |
| Casos extendidos | CU-111 Impedir desactivar la propia cuenta; CU-85 Desactivar en vez de eliminar |
| Historia de usuario | HU-26 |
| Pantalla | `/administracion/funcionarios/<id>/eliminar/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### Casos incluidos de G13

Los ejecuta el sistema dentro del caso base; no tienen actor propio.

| Identificador | Nombre | Propósito | Precondiciones | Postcondiciones | Flujo principal | Casos extendidos | Pruebas |
| --- | --- | --- | --- | --- | --- | --- | --- |
| CU-108 | Validar datos de funcionario | Verificar que los datos estén completos y cumplan las reglas. | Hay datos en el formulario. | Datos aceptados o rechazados. | Comprobar usuario único, correo, cargo y delegación. | CU-69 Informar error de validación; CU-110 Informar usuario duplicado | Caso nuevo: sin código propio en el plan de pruebas |
| CU-109 | Asignar perfil de acceso | Dejar la cuenta en uno de los cuatro perfiles. | Se guarda un funcionario con su usuario. | Usuario con un solo perfil y sus permisos. | Asignar el grupo que corresponde y quitar los demás. | Ninguno | Caso nuevo: sin código propio en el plan de pruebas |
