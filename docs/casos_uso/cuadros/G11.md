## G11 Gestionar cargos

Épica EP-08 (Administración, seguridad y trazabilidad). 4 casos de detalle para Coordinador, Administrador.

### CU-93 Registrar cargo

| Campo | Descripción |
| --- | --- |
| Identificador | CU-93 |
| Nombre | Registrar cargo |
| Actor principal | Coordinador, Administrador |
| Propósito | Incorporar un cargo nuevo. |
| Precondiciones | Sesión iniciada con permiso para agregar. |
| Postcondiciones | Cargo guardado. |
| Flujo principal | Elegir «Agregar», completar el formulario, validar y guardar. |
| Casos incluidos | CU-97 Validar datos de cargo; CU-45 Registrar en auditoría |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 |
| Pantalla | `/administracion/cargos/nuevo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-96 Eliminar cargo

| Campo | Descripción |
| --- | --- |
| Identificador | CU-96 |
| Nombre | Eliminar cargo |
| Actor principal | Coordinador, Administrador |
| Propósito | Quitar un cargo que ya no corresponde. |
