## G04 Validar actividades

Épica EP-03 (Evidencias y verificación). 2 casos de detalle para Delegado, Coordinador, Administrador.

### CU-11 Aprobar o rechazar actividad

| Campo | Descripción |
| --- | --- |
| Identificador | CU-11 |
| Nombre | Aprobar o rechazar actividad |
| Actor principal | Delegado, Coordinador, Administrador |
| Propósito | Decidir si la actividad y sus evidencias cuentan para el avance. |
| Precondiciones | Actividad de su ámbito, con evidencias pendientes y que no sea propia. |
| Postcondiciones | Decisión guardada e indicadores recalculados. |
| Flujo principal | Abrir el detalle, revisar el archivo y elegir «Aprobar» o «Rechazar» con su motivo. |
| Casos incluidos | CU-10.1 Buscar actividad por código; CU-11.1 Registrar trazabilidad de decisión; CU-06.1 Recalcular indicadores automáticamente; CU-45 Registrar en auditoría |
| Casos extendidos | CU-11.2 Bloquear aporte al avance; CU-55 Exigir motivo; CU-56 Impedir revisión propia; CU-57 Informar sin evidencias pendientes |
| Historia de usuario | HU-11 |
| Pantalla | `/actividad/<código>/aprobar/ o /rechazar/` |
| Pruebas | 18 unitarias y 21 de integración (aprobado) |

### CU-54 Anular aprobación

| Campo | Descripción |
| --- | --- |
| Identificador | CU-54 |
| Nombre | Anular aprobación |
| Actor principal | Delegado, Coordinador, Administrador |
| Propósito | Quitar la aprobación de una actividad que no debió aprobarse. |
| Precondiciones | La actividad está aprobada y el revisor no es su autor. |
| Postcondiciones | La actividad deja de sumar y se recalcula hacia abajo. |
| Flujo principal | Abrir el detalle, escribir el motivo y confirmar. |
| Casos incluidos | CU-10.1 Buscar actividad por código; CU-07.2 Recalcular por anulación de registro; CU-45 Registrar en auditoría |
| Casos extendidos | CU-55 Exigir motivo; CU-56 Impedir revisión propia |
| Historia de usuario | HU-11 |
| Pantalla | `/actividad/<código>/anular/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |
