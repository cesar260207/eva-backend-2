## G07 Gestionar ausencias

Épica EP-02 (Medición y desempeño). 3 casos de detalle para Delegado, Coordinador, Administrador.

### CU-71 Registrar ausencia

| Campo | Descripción |
| --- | --- |
| Identificador | CU-71 |
| Nombre | Registrar ausencia |
| Actor principal | Delegado, Administrador |
| Propósito | Anotar los días que un funcionario no trabajó para que no le bajen el cumplimiento. |
| Precondiciones | El Delegado solo elige funcionarios de su delegación. |
| Postcondiciones | Ausencia guardada y descontada del porcentaje esperado. |
| Flujo principal | Elegir funcionario, período, tipo (licencia, vacaciones, administrativo, compensatorio o día libre) y fechas; validar y guardar. |
| Casos incluidos | CU-74 Validar datos de ausencia; CU-45 Registrar en auditoría |
| Casos extendidos | CU-28.1 Restricción por período cerrado |
| Historia de usuario | Requerimientos de octubre |
| Pantalla | `/ausencias/nuevo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |
| Nota | La pantalla existe, pero hoy no hay enlace en el menú: lo agrega la FASE 2 del prompt. |
