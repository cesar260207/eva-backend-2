## G10 Gestionar delegaciones

Épica EP-08 (Administración, seguridad y trazabilidad). 5 casos de detalle para Coordinador, Administrador.

### CU-86 Registrar delegación

| Campo | Descripción |
| --- | --- |
| Identificador | CU-86 |
| Nombre | Registrar delegación |
| Actor principal | Coordinador, Administrador |
| Propósito | Incorporar una delegación nueva. |
| Precondiciones | Sesión iniciada con permiso para agregar. |
| Postcondiciones | Delegación guardada. |
| Flujo principal | Elegir «Agregar», completar el formulario, validar y guardar. |
| Casos incluidos | CU-91 Validar datos de delegación; CU-45 Registrar en auditoría |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 |
| Pantalla | `/administracion/delegaciones/nuevo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |
