## G03 Gestionar evidencias

Épica EP-03 (Evidencias y verificación). 2 casos de detalle para Usuario.

### CU-09 Subir evidencia

| Campo | Descripción |
| --- | --- |
| Identificador | CU-09 |
| Nombre | Subir evidencia |
| Actor principal | Usuario |
| Propósito | Respaldar la actividad con una foto o documento. |
| Precondiciones | El usuario es el autor, la actividad no está aprobada y el período está abierto. |
| Postcondiciones | Evidencia guardada con su código y pendiente de revisión. |
| Flujo principal | Desde el detalle, elegir el archivo y un comentario; el sistema valida el archivo y guarda. |
| Casos incluidos | CU-10.1 Buscar actividad por código; CU-09.1 Validar archivo de evidencia; CU-45 Registrar en auditoría |
| Casos extendidos | CU-53 Bloquear carga de evidencia |
| Historia de usuario | HU-09 |
| Pantalla | `/actividad/<código>/evidencia/` |
| Pruebas | 9 unitarias y 4 de integración (aprobado) |

### CU-52 Ver evidencia

| Campo | Descripción |
| --- | --- |
| Identificador | CU-52 |
| Nombre | Ver evidencia |
| Actor principal | Usuario |
| Propósito | Abrir o descargar el archivo que respalda una actividad. |
| Precondiciones | El usuario puede ver la actividad. |
| Postcondiciones | Archivo mostrado o descargado. |
| Flujo principal | Desde el detalle, elegir el archivo; el sistema verifica el permiso y lo entrega. |
| Casos incluidos | CU-10.1 Buscar actividad por código |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-09 |
| Pantalla | `/evidencia/<código>/archivo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |
