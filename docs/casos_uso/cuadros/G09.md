## G09 Gestionar organizaciones comunitarias

Épica EP-01 (Registro y gestión de actividades). 6 casos de detalle para Usuario, Delegado, Coordinador, Administrador.

### CU-78 Registrar organización

| Campo | Descripción |
| --- | --- |
| Identificador | CU-78 |
| Nombre | Registrar organización |
| Actor principal | Administrador |
| Propósito | Incorporar una organización nueva. |
| Precondiciones | Sesión iniciada con permiso para agregar. |
| Postcondiciones | Organización guardada. |
| Flujo principal | Elegir «Agregar», completar el formulario, validar y guardar. |
| Casos incluidos | CU-84 Validar datos de organización; CU-45 Registrar en auditoría |
| Casos extendidos | Ninguno |
| Historia de usuario | Requerimientos de octubre |
| Pantalla | `/administracion/organizaciones/nuevo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |
