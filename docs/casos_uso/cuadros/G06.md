## G06 Gestionar ajustes de puntaje

Épica EP-02 (Medición y desempeño). 4 casos de detalle para Delegado, Coordinador, Administrador.

### CU-64 Informar felicitación o reclamo

| Campo | Descripción |
| --- | --- |
| Identificador | CU-64 |
| Nombre | Informar felicitación o reclamo |
| Actor principal | Delegado, Administrador |
| Propósito | Registrar una felicitación o un reclamo formal para un funcionario o una delegación. |
| Precondiciones | Existe un respaldo formal (correo, carta o documento). |
| Postcondiciones | Ajuste «informado», pendiente de decisión. |
| Flujo principal | Elegir «Informar felicitación o reclamo» en el menú del usuario, completar tipo, origen, destinatario, período, fecha y respaldo; validar y guardar. |
| Casos incluidos | CU-68 Validar datos de ajuste; CU-45 Registrar en auditoría |
| Casos extendidos | CU-28.1 Restricción por período cerrado |
| Historia de usuario | Requerimientos de octubre |
| Pantalla | `/ajustes/nuevo/` |
| Pruebas | 0 unitarias y 1 de integración (aprobado) |

### CU-65 Consultar ajustes

| Campo | Descripción |
| --- | --- |
| Identificador | CU-65 |
| Nombre | Consultar ajustes |
| Actor principal | Delegado, Coordinador, Administrador |
| Propósito | Ver los ajustes informados, aplicados y rechazados. |
| Precondiciones | Sesión iniciada. |
| Postcondiciones | Lista mostrada; el Delegado ve solo los de su delegación y los que informó. |
| Flujo principal | Abrir el mantenedor de ajustes y filtrar. |
| Casos incluidos | CU-29 Buscar y filtrar |
| Casos extendidos | Ninguno |
| Historia de usuario | Requerimientos de octubre |
| Pantalla | `/administracion/ajustes/` |
| Pruebas | 0 unitarias y 2 de integración (aprobado) |

### CU-66 Modificar ajuste

| Campo | Descripción |
| --- | --- |
| Identificador | CU-66 |
| Nombre | Modificar ajuste |
| Actor principal | Coordinador, Administrador |
| Propósito | Corregir los datos de un ajuste. |
| Precondiciones | El ajuste existe. |
| Postcondiciones | Ajuste actualizado. |
| Flujo principal | Buscar el ajuste, cambiar los datos y guardar. |
| Casos incluidos | CU-29 Buscar y filtrar; CU-68 Validar datos de ajuste; CU-45 Registrar en auditoría |
| Casos extendidos | CU-28.1 Restricción por período cerrado |
| Historia de usuario | Requerimientos de octubre |
| Pantalla | `/administracion/ajustes/<id>/editar/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-67 Aplicar o rechazar ajuste

| Campo | Descripción |
| --- | --- |
| Identificador | CU-67 |
| Nombre | Aplicar o rechazar ajuste |
| Actor principal | Coordinador, Administrador |
| Propósito | Decidir si el ajuste informado se aplica al puntaje. |
| Precondiciones | El ajuste está «informado». |
| Postcondiciones | Ajuste aplicado (cuenta en el puntaje) o rechazado. |
| Flujo principal | Abrir la lista de ajustes, elegir «Aplicar» o «Rechazar» en el ajuste y confirmar. |
| Casos incluidos | CU-29 Buscar y filtrar; CU-45 Registrar en auditoría |
| Casos extendidos | CU-28.1 Restricción por período cerrado |
| Historia de usuario | Requerimientos de octubre |
| Pantalla | `/ajustes/<id>/aplicar/ o /rechazar/` |
| Pruebas | 0 unitarias y 6 de integración (aprobado) |
