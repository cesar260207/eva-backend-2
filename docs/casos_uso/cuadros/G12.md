## G12 Gestionar roles

Épica EP-08 (Administración, seguridad y trazabilidad). 4 casos de detalle para Administrador.

### CU-98 Registrar rol

| Campo | Descripción |
| --- | --- |
| Identificador | CU-98 |
| Nombre | Registrar rol |
| Actor principal | Administrador |
| Propósito | Incorporar un rol nuevo. |
| Precondiciones | Sesión iniciada con permiso para agregar. |
| Postcondiciones | Rol guardado. |
| Flujo principal | Elegir «Agregar», completar el formulario, validar y guardar. |
| Casos incluidos | CU-102 Validar datos de rol; CU-45 Registrar en auditoría |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 |
| Pantalla | `/administracion/roles/nuevo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |
