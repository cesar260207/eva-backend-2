## G14 Gestionar catálogo

Épica EP-08 (Administración, seguridad y trazabilidad). 4 casos de detalle para Coordinador, Administrador.

### CU-112 Registrar elemento de catálogo

| Campo | Descripción |
| --- | --- |
| Identificador | CU-112 |
| Nombre | Registrar elemento de catálogo |
| Actor principal | Coordinador, Administrador |
| Propósito | Incorporar un elemento de catálogo nuevo. |
| Precondiciones | Sesión iniciada con permiso para agregar. |
| Postcondiciones | Elemento de catálogo guardado. |
| Flujo principal | Elegir «Agregar», completar el formulario, validar y guardar. |
| Casos incluidos | CU-116 Validar datos de catálogo; CU-45 Registrar en auditoría |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-27 |
| Pantalla | `/administracion/catalogo/nuevo/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-115 Eliminar elemento de catálogo

| Campo | Descripción |
| --- | --- |
| Identificador | CU-115 |
| Nombre | Eliminar elemento de catálogo |
| Actor principal | Coordinador, Administrador |
| Propósito | Quitar un elemento de catálogo que ya no corresponde. |
| Precondiciones | El elemento de catálogo existe. |
| Postcondiciones | Registro eliminado, o desactivado si tiene datos relacionados. |
| Flujo principal | Buscar el registro, revisar la confirmación y confirmar. |

| Historia de usuario | HU-27 |
