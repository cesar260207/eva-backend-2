## G08 Gestionar atenciones sociales

Épica EP-01 (Registro y gestión de actividades). 1 caso de detalle para Profesional, Administrador.

### CU-03 Registrar atención social

| Campo | Descripción |
| --- | --- |
| Identificador | CU-03 |
| Nombre | Registrar atención social |
| Actor principal | Profesional, Administrador |
| Propósito | Anotar la gestión social hecha a un vecino por etapas. |
| Precondiciones | Ficha de funcionario. |
| Postcondiciones | Atención guardada a nombre del funcionario. |
| Flujo principal | Elegir «Registrar atención social» en el menú del usuario, completar nombre y teléfono del vecino, etapa, tipo, subtipo y observación; validar y guardar. |
| Casos incluidos | CU-76 Validar datos de atención social; CU-45 Registrar en auditoría |
| Casos extendidos | CU-77 Rechazar por máximo de tres gestiones |
| Historia de usuario | HU-03 |
| Pantalla | `/casos-sociales/nuevo/` |
| Pruebas | 3 unitarias y 1 de integración (aprobado) |
| Nota | Solo existe registrar; no hay lista para consultar ni modificar. |
