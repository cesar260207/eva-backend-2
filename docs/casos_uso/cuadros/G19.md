## G19 Consultar auditoría y perfiles

Épica EP-08 (Administración, seguridad y trazabilidad). 2 casos de detalle para Administrador.

### CU-30 Consultar auditoría de cambios

| Campo | Descripción |
| --- | --- |
| Identificador | CU-30 |
| Nombre | Consultar auditoría de cambios |
| Actor principal | Administrador |
| Propósito | Revisar quién hizo cada operación crítica y cuándo. |
| Precondiciones | Sesión iniciada como Administrador. |
| Postcondiciones | Eventos mostrados; no se pueden editar ni borrar. |
| Flujo principal | Abrir «Auditoría» y filtrar por usuario, acción, fecha o registro. |
| Casos incluidos | CU-29 Buscar y filtrar |
| Casos extendidos | CU-30.1 Bloqueo por alteración no autorizada; CU-26.1 Denegar acceso por ámbito |
| Historia de usuario | HU-30 |
| Pantalla | `/administracion/auditoria/` |
| Pruebas | 8 unitarias y 16 de integración (aprobado) |

### CU-139 Consultar perfiles y permisos

| Campo | Descripción |
| --- | --- |
| Identificador | CU-139 |
| Nombre | Consultar perfiles y permisos |
| Actor principal | Administrador |
| Propósito | Ver qué puede hacer cada perfil y sus usuarios. |
| Precondiciones | Sesión iniciada como Administrador. |
| Postcondiciones | Perfiles, permisos y usuarios mostrados. |
| Flujo principal | Abrir «Perfiles». |
| Casos incluidos | Ninguno |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 |
| Pantalla | `/administracion/perfiles/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### Casos extendidos de G19

| Identificador | Nombre | Caso base | Condición | Resultado | Pruebas |
| --- | --- | --- | --- | --- | --- |
| CU-30.1 | Bloqueo por alteración no autorizada | CU-30 Consultar auditoría de cambios | Alguien intenta modificar o borrar un evento de auditoría. | Se rechaza: la auditoría no se reescribe. | 3 unitarias y 9 de integración (aprobado) |

Usa también los casos comunes CU-29 Buscar y filtrar, CU-26.1 Denegar acceso por ámbito.
