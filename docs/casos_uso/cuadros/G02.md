## G02 Gestionar actividades

Épica EP-01 (Registro y gestión de actividades). 5 casos de detalle para Usuario, Profesional, Delegado, Coordinador, Administrador.

### CU-01 Registrar actividad

| Campo | Descripción |
| --- | --- |
| Identificador | CU-01 |
| Nombre | Registrar actividad |
| Actor principal | Usuario |
| Propósito | Registrar una gestión hecha en terreno para que cuente en su meta. |
| Precondiciones | Sesión iniciada, ficha de funcionario y período abierto. |
| Postcondiciones | Actividad «pendiente de revisión», con código EVD y su puntaje evaluado. |
| Flujo principal | Completar delegación, ítem, tipo de atención, fecha, solicitud, acción, contacto y organización; el sistema valida, genera el código, evalúa el puntaje y guarda. |
| Casos incluidos | CU-01.1 Validar campos de actividad; CU-10 Generar código verificador; CU-44 Evaluar puntaje; CU-45 Registrar en auditoría |
| Casos extendidos | CU-49 Vincular tarea del tubo de trabajo |
| Historia de usuario | HU-01 |
| Pantalla | `/actividad/nueva/` |
| Pruebas | 3 unitarias y 31 de integración (aprobado) |

### CU-41 Consultar actividades

| Campo | Descripción |
| --- | --- |
| Identificador | CU-41 |
| Nombre | Consultar actividades |
| Actor principal | Usuario |
| Propósito | Ver las actividades de su ámbito con su estado, evidencias y comentarios. |
| Precondiciones | Sesión iniciada. |
| Postcondiciones | Lista o detalle mostrado; Delegado y Profesional ven solo su delegación. |
| Flujo principal | Abrir «Actividades», buscar por código o filtrar, y abrir el detalle. |
| Casos incluidos | CU-10.1 Buscar actividad por código |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-01, HU-29 |
| Pantalla | `/actividades/ y /actividad/<código>/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-42 Modificar actividad

| Campo | Descripción |
| --- | --- |
| Identificador | CU-42 |
| Nombre | Modificar actividad |
| Actor principal | Usuario |
| Propósito | Corregir una actividad que todavía no está aprobada. |
| Precondiciones | No aprobada, período abierto, y el usuario es su autor, Coordinador o Administrador. |
| Postcondiciones | Actividad actualizada. |
| Flujo principal | Buscar la actividad, cambiar los datos y guardar; el sistema valida y vuelve a evaluar el puntaje. |
| Casos incluidos | CU-10.1 Buscar actividad por código; CU-01.1 Validar campos de actividad; CU-44 Evaluar puntaje; CU-45 Registrar en auditoría |
| Casos extendidos | CU-49 Vincular tarea del tubo de trabajo; CU-50 Bloquear cambios a la actividad; CU-51 Devolver a revisión; CU-23.1 Controlar conflicto de concurrencia |
| Historia de usuario | HU-01 |
| Pantalla | `/actividad/<código>/editar/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-43 Eliminar actividad

| Campo | Descripción |
| --- | --- |
| Identificador | CU-43 |
| Nombre | Eliminar actividad |
| Actor principal | Coordinador, Administrador |
| Propósito | Borrar una actividad registrada por error. |
| Precondiciones | No aprobada y período abierto. |
| Postcondiciones | Actividad y sus evidencias eliminadas. |
| Flujo principal | Buscar la actividad, revisar la confirmación (indica cuántas evidencias se borran) y confirmar. |
| Casos incluidos | CU-10.1 Buscar actividad por código; CU-45 Registrar en auditoría |
| Casos extendidos | CU-50 Bloquear cambios a la actividad |
| Historia de usuario | HU-01 |
| Pantalla | `/actividad/<código>/eliminar/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-24 Comentar actividad

| Campo | Descripción |
| --- | --- |
| Identificador | CU-24 |
| Nombre | Comentar actividad |
| Actor principal | Profesional, Delegado, Administrador |
| Propósito | Dejar una observación sobre la actividad para coordinar con el equipo. |
| Precondiciones | El usuario puede ver la actividad. |
| Postcondiciones | Comentario guardado y visible en el detalle de la actividad. |
| Flujo principal | Abrir el detalle, elegir «Comentar», escribir el comentario y guardar. |
| Casos incluidos | CU-10.1 Buscar actividad por código; CU-45 Registrar en auditoría |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-24 (EP-07) |
| Pantalla | `/actividad/<código>/comentario/` |
| Pruebas | 0 unitarias y 2 de integración (aprobado) |

### Casos incluidos de G02

Los ejecuta el sistema dentro del caso base; no tienen actor propio.

| Identificador | Nombre | Propósito | Precondiciones | Postcondiciones | Flujo principal | Casos extendidos | Pruebas |
| --- | --- | --- | --- | --- | --- | --- | --- |
| CU-01.1 | Validar campos de actividad | Verificar que los datos estén completos y cumplan las reglas. | Hay datos en el formulario. | Datos aceptados o rechazados con su error. | Comprobar obligatorios, fecha dentro del período, teléfono válido y organización de la misma delegación. | CU-01.2 Gestionar error de validación; CU-46 Rechazar por cierre semanal; CU-47 Rechazar por tope diario | 12 unitarias y 19 de integración (aprobado) |
| CU-10 | Generar código verificador | Dar a la actividad un código único e inmutable. | La actividad se está registrando. | Código EVD asignado. | Generar el código y asociarlo a la actividad. | Ninguno | 3 unitarias y 31 de integración (aprobado) |
| CU-44 | Evaluar puntaje | Decidir si la actividad suma al avance según las reglas de octubre. | Los datos ya se validaron. | Actividad marcada con o sin puntaje y su motivo. | Revisar si es gestión interna o previa y si tiene nombre y teléfono del contacto. | CU-48 Registrar sin puntaje | Caso nuevo: sin código propio en el plan de pruebas |

### Casos extendidos de G02

| Identificador | Nombre | Caso base | Condición | Resultado | Pruebas |
| --- | --- | --- | --- | --- | --- |
| CU-01.2 | Gestionar error de validación | CU-01.1 Validar campos de actividad | Un dato es inválido (por ejemplo, teléfono «abc»). | El formulario vuelve con el error junto al campo y no se guarda. | 5 unitarias y 19 de integración (aprobado) |
| CU-46 | Rechazar por cierre semanal | CU-01.1 Validar campos de actividad | Al registrar, la fecha es de una semana ya cerrada (cierre el martes) o es futura. | Se informa y no se guarda. | Caso nuevo: sin código propio en el plan de pruebas |
| CU-47 | Rechazar por tope diario | CU-01.1 Validar campos de actividad | Al registrar, ya hay 7 ingresos ese día (parámetro del período). | Se informa el máximo y no se guarda. | Caso nuevo: sin código propio en el plan de pruebas |
| CU-48 | Registrar sin puntaje | CU-44 Evaluar puntaje | Es gestión interna, gestión previa o falta nombre o teléfono del contacto. | Se guarda para el historial, pero no suma al avance y queda el motivo. | Caso nuevo: sin código propio en el plan de pruebas |
| CU-49 | Vincular tarea del tubo de trabajo | CU-01 Registrar actividad; CU-42 Modificar actividad | El usuario elige una tarea del tubo en el formulario (campo opcional). | La actividad queda asociada a esa tarea. | Caso nuevo: sin código propio en el plan de pruebas |
| CU-50 | Bloquear cambios a la actividad | CU-42 Modificar actividad; CU-43 Eliminar actividad | La actividad está aprobada, su período cerrado o el usuario no es su autor. | Se informa el motivo y no se cambia nada. | Caso nuevo: sin código propio en el plan de pruebas |
| CU-51 | Devolver a revisión | CU-42 Modificar actividad | La actividad estaba rechazada. | Vuelve a «pendiente de revisión», igual que sus evidencias no aprobadas. | Caso nuevo: sin código propio en el plan de pruebas |
| CU-23.1 | Controlar conflicto de concurrencia | CU-42 Modificar actividad | Otro usuario guardó el mismo registro mientras se editaba. | No se pisan sus cambios: se avisa y se pide recargar. | 5 unitarias y 18 de integración (aprobado) |
| CU-10.2 | Consulta sin coincidencias | CU-10.1 Buscar actividad por código | Ningún código o filtro coincide. | Se informa que no hay resultados. | 1 unitaria y 19 de integración (aprobado) |

Usa también los casos comunes CU-10.1 Buscar actividad por código, CU-45 Registrar en auditoría, CU-26.1 Denegar acceso por ámbito.
