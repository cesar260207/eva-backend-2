## G15 Gestionar períodos y parámetros

Épica EP-08 (Administración, seguridad y trazabilidad). 9 casos de detalle para Coordinador, Administrador.

### CU-117 Registrar período

| Campo | Descripción |
| --- | --- |
| Identificador | CU-117 |
| Nombre | Registrar período |
| Actor principal | Coordinador, Administrador |
| Propósito | Incorporar un período nuevo. |
| Precondiciones | Sesión iniciada con permiso para agregar. |
| Postcondiciones | Período guardado. |
| Flujo principal | Elegir «Agregar», completar el formulario, validar y guardar. |

### CU-28 Abrir, cerrar o reabrir período

| Campo | Descripción |
| --- | --- |
| Identificador | CU-28 |
| Nombre | Abrir, cerrar o reabrir período |
| Actor principal | Coordinador, Administrador |
| Propósito | Controlar el ciclo del período de medición. |
| Precondiciones | El período está en el estado que permite la acción. |
| Postcondiciones | Período abierto, cerrado o reabierto con nueva versión de parámetros. |
| Flujo principal | Buscar el período y elegir «Iniciar», «Cerrar» o «Reabrir». |
| Casos incluidos | CU-29 Buscar y filtrar; CU-45 Registrar en auditoría |
| Casos extendidos | CU-126 Exigir motivo de reapertura |
| Historia de usuario | HU-28 |
| Pantalla | `/administracion/periodos/<id>/estado/<acción>/` |
| Pruebas | 12 unitarias y 26 de integración (aprobado) |
