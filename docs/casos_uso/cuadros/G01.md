## G01 Gestionar acceso al sistema

Épica EP-08 (Administración, seguridad y trazabilidad). 4 casos de detalle para Usuario, Servidor de correo.

### CU-32 Iniciar sesión

| Campo | Descripción |
| --- | --- |
| Identificador | CU-32 |
| Nombre | Iniciar sesión |
| Actor principal | Usuario |
| Propósito | Entrar al SGR con su cuenta y llegar al panel de su perfil. |
| Precondiciones | El usuario tiene una cuenta activa. |
| Postcondiciones | Sesión iniciada y panel del perfil mostrado. |
| Flujo principal | Ingresar usuario y contraseña; el sistema valida y muestra el panel según el perfil. |
| Casos incluidos | CU-36 Validar credenciales |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 (RF-002) |
| Pantalla | `/login/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### CU-34 Recuperar contraseña

| Campo | Descripción |
| --- | --- |
| Identificador | CU-34 |
| Nombre | Recuperar contraseña |
| Actor principal | Usuario, Servidor de correo |
| Propósito | Recibir por correo un enlace para crear una contraseña nueva. |
| Precondiciones | La cuenta tiene correo registrado. |
| Postcondiciones | Correo enviado con un enlace de un solo uso que vence en 1 hora. |
| Flujo principal | Ingresar el correo; el sistema genera el enlace y lo envía. |
| Casos incluidos | CU-37 Enviar enlace por correo |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 (RF-002) |

### CU-35 Restablecer contraseña

| Campo | Descripción |
| --- | --- |
| Identificador | CU-35 |
| Nombre | Restablecer contraseña |
| Actor principal | Usuario |
| Propósito | Definir una contraseña nueva con el enlace recibido. |
| Precondiciones | Se recibió el enlace de recuperación. |
| Postcondiciones | Contraseña cambiada; el enlace deja de servir. |
| Flujo principal | Abrir el enlace, escribir la nueva contraseña dos veces y guardar. |
| Casos incluidos | CU-38 Validar enlace de recuperación |
| Casos extendidos | Ninguno |
| Historia de usuario | HU-26 (RF-002) |
| Pantalla | `/recuperar/<uidb64>/<token>/` |
| Pruebas | Caso nuevo: sin código propio en el plan de pruebas |

### Casos incluidos de G01

Los ejecuta el sistema dentro del caso base; no tienen actor propio.

| Identificador | Nombre | Propósito | Precondiciones | Postcondiciones | Flujo principal | Casos extendidos | Pruebas |
| --- | --- | --- | --- | --- | --- | --- | --- |
| CU-36 | Validar credenciales | Comprobar usuario y contraseña de una cuenta activa. | Se ingresaron usuario y contraseña. | Credenciales aceptadas o rechazadas. | Comparar la contraseña con su hash PBKDF2 y revisar que la cuenta esté activa. | CU-39 Informar credenciales incorrectas | Caso nuevo: sin código propio en el plan de pruebas |
| CU-37 | Enviar enlace por correo | Mandar el enlace de recuperación al correo de la cuenta. | Hay una solicitud de recuperación. | Correo entregado al servidor SMTP. | Generar el token temporal y enviarlo. | Ninguno | Caso nuevo: sin código propio en el plan de pruebas |
